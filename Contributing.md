# Contributing

Thanks for considering a contribution.

## Rules

- Tool must have a genuinely usable **free tier**, not just a time-limited trial.
- One line description, no marketing language ("best", "revolutionary", "game-changing").
- Add entries alphabetically within their category where practical.
- If your category doesn't exist yet and you think it should, open an issue first before adding it.

## Format

```markdown
- [Tool Name](https://example.com) — Plain, factual description of what it does and what's free about it.
```

## How to submit

1. Fork the repo
2. Create a branch: `git checkout -b add-tool-name`
3. Add your entry
4. Open a pull request with a short description of why it belongs

All submissions are reviewed before merging.
